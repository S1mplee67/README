## 🚀 Featured project: Duplicates by S1mplee67

My [Duplicates by S1mplee67](https://github.com/S1mplee67/duplicates-by-s1mplee67) project is a **100% offline Windows photo utility** that finds duplicate and visually similar pictures using pixel-based comparisons.

- Built in C# and .NET Framework 4.8.
- Uses dHash, aHash, an RGB color matrix, and MD5 checksums.
- Helps identify similar photos, inspect matches, and manage duplicates locally.
